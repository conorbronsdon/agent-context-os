# Context OS v0.13.1

This patch release preserves the v0.13 feature set while repairing the release
recovery path and tightening coordination-board safety reporting.

## What changed

- **Recover draft releases safely.** When GitHub's tag lookup cannot read an
  unpublished draft, staging now searches the authenticated release list across
  every page before it may create a release. It still fails closed for malformed
  responses, duplicate matches, and creation races.
- **Keep suspected credentials out of board reports.** Board posts reject the
  documented narrow credential tripwires before any write or queue action.
  Validation reports redact matching body and frontmatter values, paths,
  identifiers, and diagnostics rather than echoing them.

The unreadable v0.13.0 draft has been retained for inspection and is not
published. This immutable v0.13.1 release is its replacement.

Claude Code, Codex, and OpenClaw remain first-class hosts. Hermes Agent,
Cursor, and Devin remain experimental adapters; this release does not claim
installed-client conformance beyond their documented evidence.

From the published immutable release, download all five attached assets. Start
with `agent-context-os-template-v0.13.1.OFFLINE-VERIFY.md`; the canonical
artifact is `agent-context-os-template-v0.13.1.tar`, not GitHub's automatically
generated source archives.
