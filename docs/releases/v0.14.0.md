# Context OS v0.14.0

OpenCode joins Claude Code, Codex, and OpenClaw as a first-class host. The
release also makes handoffs inspectable and measurable, and adds opt-in live
conformance harnesses for the experimental adapters.

## What changed

- **Use Context OS from OpenCode.** Repository-native `AGENTS.md` and Agent
  Skills discovery, typed `/context-*` commands, setup and doctor
  registration, and explicit permission, privacy, and memory boundaries. An
  opt-in live harness was validated against OpenCode 1.18.27.
- **Inspect and measure handoffs.** Briefing previews name their sources,
  local receipt history is readable, and lifecycle templates ask for one
  self-contained sentence per fact. A continuity benchmark with long-sequence
  trials scores value and citation accuracy separately; its recorded runs and
  their limits are in `docs/evidence/`.
- **See what each agent can do.** The read-only `capabilities` command compares
  selected agents' claims, portable skills, support tiers, and recorded
  install state.
- **Test the experimental adapters live.** Operator-driven harnesses for
  Hermes Agent, Cursor IDE and CLI, and Devin record create-only evidence and
  never run in CI. Cursor CLI passed its controls; recorded Hermes and Cursor
  IDE runs did not, and are retained as evidence.
- **Promote coordination messages deliberately.** A board message can become a
  source-bound proposal for the decision log or session handoff, applied only
  by exact digest.
- **Expand the optional catalog.** Asana, Atlassian Rovo, and Todoist entries,
  one JSON file per entry, an evidence-freshness report, and per-host evidence
  (MarkItDown MCP is the first OpenClaw-tested entry). Nothing is installed or
  enabled by Context OS.
- **Start smaller if you want.** An experimental three-file starter covers
  sequential project work. A Codex workspace companion routes to a selected
  workspace without importing context or installing hooks.
- **Run Windows Python from WSL, MSYS, or Cygwin.** Windows Python launched
  from WSL and from MSYS/Cygwin wrappers now receives native paths and
  forwarded settings.

Claude Code, Codex, OpenClaw, and OpenCode are first-class hosts. Hermes Agent,
Cursor, and Devin remain experimental adapters; this release does not claim
installed-client conformance beyond their documented evidence.
